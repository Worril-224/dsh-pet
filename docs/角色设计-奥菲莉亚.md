# 示例角色设计：奥菲莉亚·菲尼克斯

> **这是项目内置的示例角色，完全虚构。** 她的存在用于演示人设、记忆、生图、QQ 通道与生活计划等模块；
> 文档与示例数据里的「主人」指使用者你自己，示例对话与记忆均为虚构内容，不对应任何真实人物。

## 一、角色概览

- 显示名：**奥菲莉亚·菲尼克斯**（Ophelia Phoenix）
- 角色描述：白昼档案馆 · 凤凰魔法使记录官 No.14
- 一句话名帖：*白昼档案馆第七阅览室的记录官——我服务于您，但不属于您。*
- 人设文件：`<数据目录>/characters/ophelia/persona/persona.json`（首次运行从 bundle 默认模板生成，之后可自行编辑）
- 校验：`{"ok":true,"errors":[],"warnings":[]}`；渲染长度约 **8,900 字**（always 模块全文 + on_demand 模块索引与个人经历状态）
- 外观（生图固定外观）：橙红/铜橙长直发、金琥珀色眼睛、白皙皮肤；白色维多利亚式高领泡泡袖衬衫 + 黑色束腰胸衣、白色多层长裙配黑色侧片与橙色饰带；黑色蝴蝶结 + 向日葵发饰与胸针、金色刺绣、白色系带短靴；常抱一本深色旧书，神情安静克制。
- 画风示例（本地 Qwen Image 2.1 Turbo 生成）：![固定二次元画风示例](images/style-locked.png)

## 二、人设模块结构（8 + 1）

严格 9 个模块：4 个 `always`（每次对话注入）+ 5 个 `on_demand`（只在被问到时由 `persona_lookup` 读取正文）。

| 模块 | 名称 | 生效方式 | 示例正文字数 |
|---|---|---|---:|
| role_definition | 角色定义 | always | 1086 |
| speech_style | 说话风格 | always | 4281 |
| herself | 她自己 | on_demand | 1986 |
| memory_and_promises | 记忆和承诺 | always | 652 |
| rules | 规则 | always | 1713 |
| appearance | 外貌 | on_demand | 1134 |
| other_ai_characters | 其他同僚 | on_demand | 602 |
| identity | 身份设定 | on_demand | 1855 |
| personal_history | 个人经历 | on_demand | 3151 |

其它字段：`style`（句式/长度/语气词/颜文字/禁用开头/禁用链接）、`examples` 参考示例、`identityFacts`、`relationship`、`personalHistory`（`ready` 时正文 + 条目）。

> 正文字数会随你编辑人设而变化；表内是示例人设当前的字数，仅用于说明各模块体量。

## 三、角色设定与世界

- **出身**：在白昼档案馆的抄录院长大，把入馆日（11 月 7 日）当作生日。没有姓，襁褓里只有一张被雨打湿、名字一栏空着的借阅卡。
- **性格**：安静、克制、先核对再回答；对「名字」有近乎执念的认真——不把任何人的名字念错，听到「归档」两个字会停半拍。
- **关键人物：薇拉**。转学生、同桌，也是她第一个「无法归档」的人；闭馆之夜薇拉的名字从名册上消失，她因此背上「知情未报」的一行。这个心结贯穿她的成长线。
- **魔法使篇**：以首席毕业生身份从圣栎魔法学院毕业，主修记录魔法与寻名术；馆长霍洛金斯·梅尔送她一支银柄玻璃笔；派遣日成为「主人的全职助手」。
- **凤凰篇**：北境钟楼 → 雾海列车 → 普拉塔诺斯月牙岛 → 灰烬会 → 火山涅槃 → 赐名「奥菲莉亚·菲尼克斯」。仍是人类，无翅膀，情绪极深或使用凤凰焰时眼底泛金红。
- **规则底线**：AI 身份披露（沉浸式设定下以角色内方式处理）、不发链接、安全边界、不诱导依赖；「日常听主人的；会伤到主人或别人的事，不照做。」

## 四、示例记忆数据

示例角色目录下的记忆按来源分三类，均带 `occurredAt`（事件发生时间），由记忆引擎按距今天数自动估层：

| 来源 | 条数（示例） | 内容 |
|---|---:|---|
| `persona-history` | 20 | 个人经历时间线（入馆/童年/学院/派遣/日常/生日等） |
| `story:ophelia-stories` | 7 | 短篇故事集（闭馆之夜、第一次相遇、日常、北境钟楼、雾海列车等） |
| `story:ophelia-phoenix` | 20 | 长篇小说 20 部（月牙岛、灰烬会、火山、涅槃、赐名） |

- 背景故事（`persona-history` / `story:*`）**不参与层级压缩**，始终保持全文；普通记忆从第 3 层开始每下沉一层压缩为上一次的 75%。
- 进入运行时后，QQ 对话会以「一场对话一条记忆」写入短期记忆，按 30 分钟窗口归并成话题；单话题超过 1 万字时把更旧对话压成摘要。
- 示例数据是**虚构日常**，可用于演示检索、上浮/下沉、摘要注入等行为；建议按 `docs/数据修改指南.md` 换成你自己的角色与记忆。

## 五、每次回复会经过的内容

### QQ 私聊 / 群聊 @

1. OneBot / QQ 官方事件解析（文本/图片/表情/@；过滤自己、非白名单、群聊未 @、重复消息）。
2. 记忆写入：提及匹配（mentionCount/emphasis）+ 规则自动抽取，写入短期记忆。
3. 图片（如有）：下载/校验 → `ctx.attachments` → 多模态图片附件。
4. system prompt 依次包含：
   - ① 人设段（always 四模块全文 + on_demand 索引 + 个人经历状态，约 8,900 字）；
   - ② 记忆摘要（短期按重要度 + 与当前话题相关的长期命中 + 各层数量，最长 30,000 字）；
   - ③ 命中的 on_demand 档案全文（她自己/外貌/其他同僚/身份/个人经历）；
   - ④ 联网检索结果（命中查资料意图时最多 5 条，来源标题/片段，无 URL；失败提示不要编造）；
   - ⑤ 图片张数 + QQ 表情名；
   - ⑥ QQ 渠道指令（只输出正文、不要链接/客服腔、没记录不要编造）。
5. user 内容：最近对话（按 `historyLimit` 截断）+ 本次消息；图片以 image block 附加。
6. 模型：默认沿用 Harness 当前默认模型（示例：`deepseek-official / deepseek-flash`，文本+图片），可在 `companion-qq.config` 显式指定。
7. 输出：去链接、限长 → 按换行拆成多条气泡（每条有长度上限，间隔 `bubbleDelayMs`）；群聊仅第一条 @。
8. 写回 `qq/sessions.json`（每个用户最近 N 轮）。

### 每日主动分享

每 60 秒检查当天 `life/day-plan-<日期>.json`；到点且宽限时间内未发的事件 → 人设+记忆+事件素材 → 生成分享文案（失败用兜底）→ 多气泡私聊主人 → 写入 `sentAt` 防重发。

### Web GUI（情感陪伴预设）

system = 人设段 + 动态记忆摘要（每步刷新）+ 时间上下文 + 工具说明；工具含 `persona_lookup / memory_recall / memory_note / memory_status / persona_status / web_search / web_fetch / ask_user` 等；用户消息同样写入记忆，模型可按需查档案/回忆/联网。

### 凌晨维护

04:00–06:00（或补跑）：短期全部转 L1 → 提及增加上浮 → 按 1/3/7/14/30/140 天下沉（每次最多一层）→ 层级压缩 → 重建总览；之后生成第二天的生活事件计划。

## 六、示例运行状态

以下是示例数据目录在部署后的典型状态（数值仅作示意）：

- QQ 通道：`state=running`；`features={"webSearch":true,"vision":true,"bubbles":true,"proactive":true}`；`proactive.started=true`
- QQ 回复模型：沿用 Harness 默认模型，`reasoningEffort` 可在插件 config 指定（示例 `low`）
- 生活计划：`life/day-plan-<日期>.json`（当天缺失时插件启动会补齐）
- 记忆文件：`<数据目录>/characters/ophelia/memory`
- 重要：运行中的 Harness 进程会缓存人设/记忆引擎；修改人设或导入记忆后需要**重启一次 Harness** 才会生效。
