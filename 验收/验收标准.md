# 验收标准与用例矩阵 v1.0（公开版）

对应 `docs/SPEC.md`；验收编号在测试文件注释中引用。公开版沿用原项目的编号体系（118 条验收用例 / 25 个模块组），
其中依赖一次性私有脚本或私有故事数据集的条目已标注为「历史验收项」，不随公开仓库提供对应测试。

## A. 记忆模块（M）

| 编号 | 验收项 | 判定标准 | 自动化 |
|---|---|---|---|
| M1 | 记忆字段完整性 | 每条记忆含 id/content/summary/keywords(3~12)/category/mentionCount/emphasis/importance/clarity/firstSeenAt/lastMentionedAt/layer/history；内容为中文 | 单元测试 |
| M2 | 关键词规则 | 3~12 个、顺序保留、>5 截断、<3 自动补足；越重要的越靠前（调用方顺序不被重排） | 单元测试 |
| M3 | 重要性/清晰度公式 | 与 SPEC 4.2 完全一致；清晰度分档渲染（清晰/一般/模糊）可区分 | 单元测试 |
| M4 | 提及次数与强调 | 用户消息命中关键词 → mentionCount+1、lastMentionedAt 更新；同一 messageId 不重复计数；强调词提升 emphasis | 单元测试 |
| M5 | 自动抽取 | 「我叫/我喜欢/我不喜欢/记住/我的生日…/我今天…/我难过…」等 7 类模式能抽取中文记忆；每条消息最多 3 条；重复内容不新增 | 单元测试 |
| M6 | 短期记忆溢出 | 超过容量后最早的 floor(n/2) 条转入长期第一层，history 记录原因 | 单元测试 |
| M7 | 每日夜间转移 | maintain 后短期记忆清空，全部进入第一层；关键词/分类被补齐；index.json 生成 | 单元测试 |
| M8 | 七层衰减阈值 | 1/3/7/14/30/140 天六个阈值逐一验证：到期下沉一层，未到期不动；第七层不再下沉；每次最多移动一层 | 单元测试 |
| M9 | 提及频率增加上浮 | 维护时 delta>=1 且 layer>1 → 上浮一层；与下沉互斥且提升优先 | 单元测试 |
| M10 | 分级检索 | 短期→第一层→…→第七层顺序检索；达到 limit 提前停止；关键词/分类命中；空 query 返回短期高重要记忆 | 单元测试 |
| M11 | 上下文紧张压缩 | 按重要度保留一半写入短期记忆，返回 kept/dropped/stored；随后触发溢出转移 | 单元测试 |
| M12 | 维护调度 | 4:00–6:00 窗口内且当天未跑 → 执行；当天 6 点后未跑 → 补跑；已跑过 → 不重复；跨天再次触发 | 单元测试 |
| M13 | 持久化与可读性 | 原子写入；重启（新引擎实例）后数据完整；记忆总览.md 含中文表格；events.jsonl 可读 | 单元测试 |
| M14 | 摘要注入 | renderDigest 含短期记忆/长期命中/概况/检索提示；长度 ≤ maxChars；空库提示正确 | 单元测试 |
